At **Crystal Studio Labs**, we take the security of **Krishi Setu AI** and its users seriously. Since this platform serves rural communities and acts as a Digital Public Good, safeguarding the integrity of our offline models and data pipelines is our highest priority.

## 📌 Supported Versions

We actively monitor and provide security patches for the following versions of Krishi Setu:

| Version | Status |
| :--- | :--- |
| 1.x.x (Main) | ✅ Supported |
| < 1.0 (Alpha/Beta) | ❌ Unsupported |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability within the Krishi Setu application, the underlying TensorFlow.js models, or the API integrations, please **DO NOT** create a public GitHub issue. 

Instead, please report it immediately via email:

📧 **Contact:** [contact@sahooshuvranshu.is-a.dev](mailto:contact@sahooshuvranshu.is-a.dev)

### What to include in your report:
- A detailed description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on the system or end-users.

All security vulnerabilities will be promptly addressed by the Crystal Studio Labs team. We will acknowledge your email within 48 hours and keep you updated on our progress toward a fix. We appreciate your efforts to responsibly disclose your findings.
