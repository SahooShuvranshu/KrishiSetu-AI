## 📝 How Can I Contribute?

### 🐛 Reporting Bugs
Bugs are tracked as [GitHub issues](https://github.com/SahooShuvranshu/KrishiSetu-AI/issues). When creating an issue, please:
- Explain the problem clearly.
- Include OS/Browser details.
- Provide step-by-step instructions to help maintainers reproduce the bug.

### 💡 Suggesting Enhancements
Enhancement suggestions are also tracked as GitHub issues. When creating a suggestion, please:
- Provide a clear and descriptive title.
- Explain *why* this enhancement would be useful to the farmers or the developers.
- Include mockups or pseudocode if applicable.

### 🚀 Pull Requests (PRs)
1. **Fork** the repository and create your branch from main.
2. **Commit** your changes with clear, descriptive commit messages.
3. **Test** your code. If you've added features that require unit testing, please add them.
4. **Document** your changes. If you've changed APIs or features, update the README.md or relevant files.
5. **Open a PR!** We will review it as soon as possible.

## 💻 Local Development Setup

To get Krishi Setu running on your local machine:

1. **Clone your fork**:
   `ash
   git clone https://github.com/<your-username>/KrishiSetu-AI.git
   cd KrishiSetu-AI
   `
2. **Install dependencies**:
   `ash
   npm install
   `
3. **Configure Environment Variables**:
   Create a .env file in the root directory and add your Gemini API key:
   `env
   VITE_GEMINI_API_KEY=your_google_gemini_api_key
   `
4. **Run the Development Server**:
   `ash
   npm run dev
   `
5. **Access the App**:
   Open [http://localhost:5173](http://localhost:5173) in your browser.
