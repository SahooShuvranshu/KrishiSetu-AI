# Contributing to Krishi Setu AI

First off, thank you for considering contributing to Krishi Setu! It's people like you that make this tool an incredible digital public good for Indian farmers.

## How Can I Contribute?

### Reporting Bugs
Bugs are tracked as GitHub issues. When creating an issue, please explain the problem and include additional details to help maintainers reproduce the problem.

### Suggesting Enhancements
Enhancement suggestions are tracked as GitHub issues. When creating an enhancement suggestion, please provide a clear and descriptive title and a detailed description of the proposed enhancement.

### Pull Requests
1. Fork the repo and create your branch from \main\.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs or features, update the documentation.
4. Ensure the test suite passes.
5. Issue that pull request!

## Local Development
1. Clone your fork.
2. Run \
pm install\ to install dependencies.
3. Run \
pm run dev\ to start the Vite development server.
4. Access the app via \http://localhost:5173\.

Thank you for building a better future for agriculture!
