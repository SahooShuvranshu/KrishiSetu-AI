That is exactly what we built."*

* **Visual in Video**: Show [`screenshots/02_home_dashboard_top.png`](screenshots/02_home_dashboard_top.png).

When an infection strikes a paddy or cotton field, extension officers are days away, and internet connectivity is non-existent. Most agritech solutions fail immediately the second the signal drops. KrishiSetu is built from the ground up to never fail offline."*

### Scene 3: 100% Offline-First Architecture (0:25 - 0:38)
* **Visual in Video**: Show [`screenshots/03_home_dashboard_offline_readiness.png`](screenshots/03_home_dashboard_offline_readiness.png) focusing on the "AI MODEL READY // 100% OFFLINE" status card.
* **On-Screen Text**: `EDGE AI // PERSISTENT PRIVATE FILE STORAGE (OPFS)`
* **Spoken Narration (Voiceover)**:
  > *"KrishiSetu is an industrial Progressive Web App powered by TensorFlow.js. The quantized neural network is stored directly inside the browser's Origin Private File System. It survives device restarts, cache clears, and airplane mode. No remote server is ever needed to diagnose a crop."*

---

### Scene 4: Precision On-Device Scanner (0:38 - 0:52)
* **Visual in Video**: Show [`screenshots/04_camera_scan_view.png`](screenshots/04_camera_scan_view.png) showing the 5 crop categories (Paddy, Cotton, Tomato, Potato, Maize).
* **On-Screen Text**: `DYNAMIC CROP MASKING // ZERO HALLUCINATIONS`
* **Spoken Narration (Voiceover)**:
  > *"The farmer selects their crop and captures the leaf using the live camera or gallery upload. Dynamic crop masking renormalizes model probabilities strictly within that plant's pathology space, preventing cross-crop misdiagnoses, while green-spectrum guards reject non-leaf objects automatically."*
